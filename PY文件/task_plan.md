# 任务计划：用户级数据、语音跟踪统计工具 V2.5.6 升级

## 目标
将用户级数据、语音跟踪统计工具从 V2.5.5 升级到 V2.5.6，实现 6 大改动。

## 阶段

### 阶段 1：版本号更新 [complete]
- 文件名：V2.5.5 → V2.5.6
- docstring：V2.5.5 → V2.5.6
- version 变量：V2.5.5 → V2.5.6
- 窗口标题：V2.5.5 → V2.5.6
- 关于对话框标题：V2.5.5 → V2.5.6
- 关于对话框更新记录：新增 V2.5.6 条目

### 阶段 2：新增"合并原始数据"复选框 [complete]
- 速率统计标签：在参数设置最后增加 `self.cb_merge_raw`
- VQI 标签：在开始/结束时间后增加 `self.vqi_cb_merge_raw`
- WorkerThread/VqiWorkerThread：增加 merge_raw 参数传递
- 默认状态：打勾

### 阶段 3：批注辅助函数实现 [complete]
- 添加 `_add_calc_comment` 函数
- 在"汇总-数据和语音"sheet 应用批注（标准行除外）
- 在"按文件名"sheet 应用批注
- 在"按运营商"sheet 应用批注

### 阶段 4：数据文件处理（process_vqi 改造）[complete]
- 数据文件检测：只读前 3 行判断类型（nrows=3）
- 数据文件读取：合并、加运营商列、加业务类型列
- 数据指标计算：下行/上行前 10%峰值、均值速率
- 按文件名表：数据文件行（通话轮次=0，呼叫建立时长=''，优质通话占比=''）
- 按运营商表：填充数据指标

### 阶段 5：输出 Sheet 完善 [complete]
- merge_raw=True：输出 7 个 sheet（语音/数据原始文件 + 5 个统计 sheet）
- merge_raw=False：只输出 5 个统计 sheet
- Sheet 命名规范：
  1. 语音业务-原始文件
  2. 数据业务-原始文件
  3. 语音指标统计
  4. MOS3.5计算明细
  5. 汇总-数据和语音
  6. 按文件名
  7. 按运营商

### 阶段 6：性能优化 [complete]
- 文件类型判断：只读前 3 行（nrows=3）
- 缓存已读取的文件列表
